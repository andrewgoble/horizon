What broke, and the one-line fix

! Why it broke

Recommendations render client-side into a content div that the server template leaves empty. Horizon re-renders the cart drawer on every cart change — and during page-load hydration — via morphSection().

The morph diffs the live DOM against the empty server markup and removes the rendered carousel. The component only reloaded when data-product-id changed, so any update that kept the same first item left the upsells permanently empty.

✓ The fix

Mark the element so Horizon's morph skips its subtree — the same hint the theme already uses elsewhere. Element attributes still morph, so product changes still trigger a fresh fetch.

<cart-upsells
  data-product-id="{{ ... }}"
  data-skip-subtree-update
>
